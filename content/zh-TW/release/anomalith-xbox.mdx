## 核心玩法：「潛入、回收、返回」的生存循環

遊戲的核心節奏遵循緊張刺激的撤離式生存恐怖循環。玩家將潛入不可預測的環境中，管理稀缺的彈藥，擊敗被稱為「異常體」（Anomalies）的超現實實體，並在找到撤離點前確保珍貴文物的安全。

如果您喜歡融合了體力管理、精準射擊和陰森音效設計的戰術第三人稱射擊遊戲，那麼持續追蹤 **anomalith xbox** 的最新動態絕對值得。

### 關鍵遊戲機制

1. **戰略性武器庫管理：** 子彈和恢復鎮靜劑十分稀缺。您必須在積極射擊與戰術撤退之間取得平衡。
2. **異常化技能：** 玲央奈可以施展專門的超自然技能，用於控場、個人防禦以及高額爆發傷害。
3. **裝備製作與升級：** 回收的「異常物件」可在工坊中拆解，用於打造新槍械或自訂屬性。
4. **外觀幻化系統：** 玩家屬性與角色外觀分離，讓您在不犧牲防禦力的情況下自由搭配服裝。

| 生存要素 | 機制與玩家決策 |
| :--- | :--- |
| **探索** | 穿梭於不斷變換的閾限走廊、辦公樓和昭和風街巷。 |
| **資源管理** | 隨時注意彈匣數量、治療鎮靜劑以及背包負重。 |
| **戰鬥戰術** | 根據敵人的弱點在霰彈槍、步槍和手槍之間靈活切換。 |
| **撤離風險** | 抉擇是要深入冒險獲取稀有戰利品，還是安全帶回當前收益。 |
