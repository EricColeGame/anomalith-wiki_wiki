## 故事概述與世界觀：19** 年的「異界」

故事設定在架空的 20 世紀末日本（標記為「19**」年），核心劇情圍繞著被稱為「異界」的空間裂隙所引發的日益嚴重的危機展開。當日常環境扭曲成充滿敵意、令人費解的閾限空間（liminal zones）時，政府專門設立的「危險區域對策室」陷入了難以招架的困境。

玩家將扮演 **水無月玲奈（Reona Minazuki）**，這名調查員在名為「石棺」的異象構造體中經歷了長達十年的昏睡後甦醒。帶著超常感知能力醒來的玲奈，天生對異常現象有著敏銳的感知。她與對策小組並肩作戰，展開危險的深入調查，在保護倖存平民的同時，解開摯友失蹤背後的謎團。

| 敘事元素 | 說明 / 遊戲內功能 |
| :--- | :--- |
| **主角** | 水無月玲奈，沉睡 10 年後甦醒、具備異界感知能力的調查員。 |
| **主要舞台** | 19** 年的日本，飽受扭曲空間位移與閾限異象的困擾。 |
| **關鍵組織** | 危險區域對策室，負責研究並壓制維度威脅。 |
| **核心衝突** | 阻止異象入侵、穩定現實維度，並揭開區域內的個人羈絆之謎。 |
| **背景文獻** | 超過 200 份可收集的調查報告，詳細解說未知實體與區域生態。 |

## 遊戲機制：槍戰、近戰與「亞人化」系統

正如實機遊玩畫面所示，本作巧妙融合了生存恐怖經典的資源管理與快節奏的第三人稱戰鬥。敵人飄忽不定的行動模式，考驗著玩家的戰術走位、精準彈藥計算以及近身處決時機。

### 戰鬥流程與生存要素

戰鬥的核心在於先以槍械拉開距離，再伺機近身消滅露出破綻的目標。透過精準射擊使怪物失衡硬直，便能發動高傷害的近戰處決。

要在扭曲的環境中生存，還必須適應種種超現實的險境，例如重力反轉的房間與無止盡的交通迴廊。

```
戰鬥循環：
[偵測威脅] ➔ [控管距離 / 彈藥] ➔ [擊暈目標] ➔ [發動近戰處決] ➔ [採集精華]
```

### 「亞人化」能力系統

由於玲奈曾暴露在異常能量中長達十年，她能直接從被擊敗的怪物身上汲取獨特的主動技能與被動增益。透過 **亞人化系統（Demi-Humanization System）**，玩家可以量身打造專屬的角色構築，無論是偏好匿蹤潛伏、激進近戰還是精通遠程武器皆可自由選擇。

| 系統 / 功能 | 機制與玩家影響 | 戰略價值 |
| :--- | :--- | :--- |
| **第三人稱槍戰** | 針對敵人飄忽不定的行為模式進行精準瞄準。 | 中遠距離削弱敵方威脅。 |
| **擊暈與近戰處決** | 在敵對實體失衡硬直後發動強力的物理重擊。 | 節省寶貴的槍械彈藥。 |
| **亞人化** | 可裝備源自異象的各類主動技能與被動增益。 | 決定角色構築方向與功能特性。 |
| **道具欄管理** | 採用格子/欄位制的物品追蹤，資源攜帶量有限。 | 促使玩家規劃探索路線並謹慎拾取物資。 |
| **基地營地養成** | 提供武器製作、NPC 對話與解鎖升級的據點。 | 在每次出擊探索之間調整整備裝備配備。 |

## 常見問題解答 (FAQ)

### 《Anomalith》將在什麼平台上發售？
本作預計於 2026 年 10 月 29 日在 Nintendo Switch 2 平台上推出。

### 《Anomalith》首支預告片展示了什麼樣的遊戲風格？
預告片主打第三人稱生存恐怖玩法，包含戰術槍戰、對失衡敵人發動近戰處決、閾限空間探索以及「亞人化」技能樹系統。

### 本作由誰開發與發行？
本作由 Winning Entertainment Group（原 Natsume Atari）開發、FuRyu 發行，音樂由北村友香負責創作，劇本則由田中羅密歐執筆。

### 遊戲發售時的售價是多少？
標準版售價為 49.99 美元，數位豪華版售價為 69.99 美元。
