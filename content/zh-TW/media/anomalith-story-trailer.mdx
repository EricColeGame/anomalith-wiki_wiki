## 世界觀與背景設定：踏入扭曲的「異界」

宣傳影像中呈現的故事設定在一個充滿復古未來感與未知恐懼的前提下。故事發生在 20 世紀末（19\*\* 年）的某個未指明年份，世界正面臨被稱為「異界」的突發性現實破裂威脅。這些空間異常徹底顛覆了物理法則，將尋常的日常建築困在超現實且危機四伏的奇異形態之中。

政府的專屬防衛部隊「危險區域對策室」發現自己完全陷入被動，且無法追查到這些裂縫的源頭。玩家將扮演水無月玲央奈（Reona Minazuki），一名精銳調查員，她從被稱為「石棺」的神秘異常物體中結束了長達十年的沉睡並甦醒過來。

| 世界觀要素 | 說明 | 劇情定位 |
| :--- | :--- | :--- |
| **異界（Otherworlds）** | 充斥著敵對實體、扭曲現實的空間裂隙。 | 主要任務環境與地下城舞台。 |
| **危險區域對策室** | 負責處理與收容異常現象的政府機構。 | 玲央奈的所屬單位兼作戰基地。 |
| **石棺（The Sarcophagus）** | 將玲央奈封印了長達 10 年的神秘異常體。 | 玲央奈獲取神秘超自然能力的源泉。 |
| **水無月玲央奈** | 甦醒的調查員，對異常具備敏銳的感應能力。 | 為了拯救摯友而展開行動的玩家主角。 |
| **調查報告** | 散佈在各關卡中超過 200 份的可收集世界觀文件。 | 豐富背景設定並記載敵人弱點的檔案。 |

由於長時間處於封閉狀態，玲央奈對這些外來空間展現出獨特的敏銳感應。她的個人任務不僅僅是履行政府職責；她深入空間裂縫是為了拯救珍貴的同伴，同時試圖阻止全球走向崩潰。

## 核心玩法機制與生存系統

本質上，這款遊戲是一款生存第三人稱射擊遊戲，資源管理的重要性絲毫不亞於玩家的瞄準技術。難以捉摸且飢腸轆轆的怪物徘徊在閾限空間之中——例如顛倒的住宅公寓與永無止境的通勤列車——極度考驗玩家的臨場應變能力。

實機畫面展現了流暢的射擊手感，並輔以在目標陷入硬直時可發動的強力近戰終結技。若想順利生存，玩家必須謹慎平衡背包物品、監控彈藥存量，並巧妙利用空間環境陷阱。

```
[遭遇異常生物] ➔ [透過射擊造成硬直傷害] ➔ [發動強力近戰終結技] ➔ [萃取異常精華]
```

### 亞人化系統（Demi-Humanization System）

玩法概覽中最引人注目的核心機制是「亞人化系統」。利用玲央奈與裂縫的內在連結，玩家可以從被擊敗的實體身上汲取外來特質，進而解鎖一系列主動戰鬥技能與被動生存增益。

| 系統類別 | 機制與效果 | 戰術應用 |
| :--- | :--- | :--- |
| **主動裂隙異能** | 念力爆發、相位閃避、感官探測。 | 逃離狹窄走廊並破壞敵方防禦架式。 |
| **被動異化突變** | 增加彈藥容量、強化近戰衝擊力、聲音追蹤。 | 長期地下城生存與資源節約。 |
| **硬直處決機制** | 高衝擊力彈藥使實體露出破綻以供處決。 | 透過近身戰終結敵人以節省彈藥。 |
| **方格背包系統** | 攜帶急救包、彈藥箱與神器的有限空間。 | 每次進入異界前必須進行策略性規劃。 |

## 深度自定義：裝備、神器與外觀穿搭

與傳統嚴格限制玩家自由度的生存遊戲不同，本作高度強調深度的配裝構建（Build）與視覺外觀表現。裝備選擇將直接影響戰鬥數值、幸運加成以及防禦抗性。

根據開發團隊透露，玲央奈擁有九個獨立的外觀自定義部位，並提供超過 300 種獨特的外觀道具。這些部件允許玩家在不犧牲生存實用性的前提下，自由打造戰術風、休閒風或超現實風的造型。

| 自定義層級 | 種類總數 / 部位 | 玩法影響 |
| :--- | :--- | :--- |
| **武器軍火庫** | 多樣化的實彈、爆炸與能量槍械 | 決定主要的傷害輸出與有效交戰距離 |
| **武器配件** | 瞄準鏡、擴充彈匣、消音器、特化槍管 | 調整後坐力、換彈速度與暴擊率 |
| **神器槽位** | 從異常核心收集而來的超自然遺物 | 賦予主動特技、幸運加成或高風險詛咒 |
| **外觀部件** | 涵蓋 9 個身體部位的 300 多件道具 | 全面自定義水無月玲央奈的視覺造型 |

在每次出擊的間隙，玩家會返回中央行動基地。在此處與小隊成員及指揮官互動，可以解鎖至關重要的武器升級，並進一步揭示背景劇情的蛛絲馬跡。

## 常見問題解答 (FAQ)

### 《ANOMALITH》故事預告片的主要重點是什麼？
預告片介紹了主角水無月玲央奈、她從神秘「石棺」中的甦醒，以及她在「危險區域對策室」的指派下，深入被稱為「異界」的超現實空間異常進行探索的使命。

### 這款遊戲的正式發售日期是什麼時候？
根據 **ANOMALITH 故事預告片** 的公告，該遊戲將於 **10 月 29 日** 在 PlayStation 5、Nintendo Switch 2 以及 PC（Steam）平台上推出。

### 「亞人化系統」是如何運作的？
亞人化系統允許玲央奈直接從被擊敗的異常生物中吸收超自然特質。這能為玩家提供豐富的主動戰鬥技能與被動生存強化，並可在整個戰役過程中持續升級。

### 遊戲中可以自定義武器和服裝嗎？
可以。遊戲具備深度的模組化武器改裝系統（包含配件與神器），並提供分佈在九個外觀裝備部位、超過 300 種的外觀服裝可供自由搭配。
