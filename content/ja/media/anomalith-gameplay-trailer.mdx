## ストーリーと世界観設定：19**年、歪められた日本の「異界」

レトロフューチャーな架空の時代「19**年」の日本を舞台に、突如発生した壊滅的な空間の裂け目**「異界」**によって世界は分断されました。これらの次元の異変は物理法則を歪め、予測不能で凶暴な怪物「アノマリー」を生み出しています。

```
[「石棺」の中での10年間の眠り] 
               │
               ▼
[水無月レオナが特異な知覚能力に目覚める]
               │
               ▼
[危険区域対策室への配属・出撃]
               │
               ▼
[リミナルスペースへ潜入し、行方不明の親友を救出]
```

プレイヤーは、政府の特別組織「危険区域対策室」の捜査官である**水無月レオナ**を操作します。10年前、レオナは「石棺」と呼ばれる謎の異変の中に閉じ込められていました。恐怖に侵食された世界で目覚めた彼女は、自らが「異界」の変動を感知する超常的な知覚能力を持っていることに気づきます。生き残った市民を守り、混乱の中で消息を絶った大切な親友を探し出すため、レオナは空間異変の最深部へと足を踏み入れます。

## 戦闘メカニクスと「亜人化（Demi-Humanization）」システム

**『Anomalith』ゲームプレイトレーラー**で公開された映像から、戦闘が従来のテンポの遅いサバイバルホラーよりもはるかにダイナミックであることが確認できます。プレイヤーは精密な三人称視点シューティング、強烈な近接戦闘、そして生体機械的な超常能力を状況に応じて使い分ける必要があります。

| 戦闘要素 | 主な役割 | 戦術的な活用法 |
| :--- | :--- | :--- |
| **三人称視点シューティング** | 遠距離制圧＆弱点狙撃 | 俊敏で変則的な動きの怪物を安全な距離から無力化 |
| **スタン近接フィニッシュ** | 高威力のトドメの一撃 | 弾薬を節約しつつ大型の敵をダウンさせる |
| **亜人化スキル** | 異変エネルギーを用いたアクティブ／パッシブ技 | 現実を歪める攻撃、回避、集団の敵の足止め |
| **アーティファクト注入** | 武器特性の強化・付与 | 属性ダメージ、弱体効果、ハイリスク・ハイリターンな火力強化を追加 |

### 変則的な敵AIへの対処

『ANOMALITH』の怪物は決まったルートを巡回するだけではありません。**『Anomalith』ゲームプレイトレーラー**の戦闘シーンにあるように、アノマリーは壁を跳び越え、歪んだ地形を利用して回り込み、物音に対して過敏に反応します。

1.  **敵を怯ませる（スタン）：** 精密な射撃で特定の部位を狙い、無防備なスタン状態を作り出す。
2.  **近接テイクダウンの発動：** 素早く間合いを詰め、強力な近接攻撃で仕留めて貴重な銃弾を温存する。
3.  **亜人化能力の活用：** 倒したアノマリーからコアを吸収してレオナの「亜人化」スキルツリーを強化し、念動ダッシュや防御バリアなどを解放する。
