## 公式ゲームプレイ映像から見る戦闘システム

新たに公開された映像では、精密な射撃、敵の不規則な挙動パターン、そして遠距離攻撃と近接攻撃のスムーズな連携を中心とした戦闘ループが描かれています。アノマリー（異形）ホラーの定番通り、標準的な敵でさえ直線的に突撃してくることは稀で、痙攣するように動き、テレポートし、プレイヤーの空間認識を狂わせてきます。

### 三人称視点ガンプレイと近接とどめ攻撃（メレーサブミッション）

プレイヤーは肩越し視点で照準を合わせ、敵対するアノマリーの急所を狙い撃ちます。十分な衝撃力や属性ダメージを与えることでアノマリーは怯み（ステッガー）状態に陥り、強力な近接テイクダウンを叩き込むチャンスが生まれます。

| 戦闘フェーズ | プレイヤーのアクション | 戦術的メリット |
| :--- | :--- | :--- |
| **通常交戦** | 距離管理 ＆ 弱点への精密射撃 | 包囲を防ぎ、貴重な回復アイテムを節約 |
| **怯み（ステッガー）発生** | 継続射撃 / 爆発物による攻撃 | アノマリーを行動不能にし、攻撃を中断させる |
| **近接フィニッシャー** | 近距離での物理的とどめ攻撃 | 弾薬を追加消費することなく脅威を排除 |
| **リセット・立て直し** | 素早いタクティカルリロード ＆ 位置取り直し | 側面から迫る敵に対する射線・視界を再確保 |

**ANOMALITH official gameplay**のデモ映像を見ると、リソースの節約がいかに最重要であるかがよく分かります。無駄撃ちを続ければすぐに予備弾薬が底をつき、逃げ場のない閉所空間で絶体絶命の危機に陥ることになります。

## リミナルスペースの探索と「亜人化システム」

**ANOMALITH official gameplay**トレーラーでひときわ目を引く要素の一つが、異界における建築構造の不安定さです。環境は通常の物理法則に従わず、重力が反転したマンション群や無限に続く地下鉄車両など、シュールで方向感覚を失わせる構造物の探索を強いられます。

```
[ 異界の裂け目（Otherworld Rift）へ進入 ]
         │
         ▼
[ リミナル・アノマリーの探索（重力反転、無限ループなど） ]
         │
         ▼
[ アノマリーの生体データ ＆ アーティファクトの回収 ]
         │
         ▼
[ 「亜人化能力」（アクティブ / パッシブスキル）の覚醒 ]
         │
         ▼
[ 対策室の拠点へ帰還して強化・アップグレード ]
```

### 亜人化（Demi-Humanization）システム

レオナは「棺」の中で10年間を過ごした影響により、**亜人化システム**を通じてアノマリーの特性を取り込むことができます。このシステムにより、プレイヤーは以下のような能力を装備・変異させることが可能です。

*   **アクティブ・アノマリースキル:** 現実を歪める高速ダッシュ、局所的な空間バリア、衝撃波攻撃など。
*   **パッシブバフ:** アノマリーの知覚能力向上、窮地でのリロード速度上昇、敵の気配を追跡する感覚など。
*   **アーティファクト調整:** 異界内で発見した希少な遺物を装備し、状況に応じた恩恵を獲得（多くの場合、ハイリスク・ハイリターンのトレードオフが存在）。

## 奥深いカスタマイズと拠点管理

その場限りのサバイバルにとどまらず、拠点では本格的なRPG要素が展開されます。次元潜入の合間に、レオナは「危険区域対策室」の仲間たちと交流し、収集した情報を任務上のアドバンテージへと変換していきます。

| カスタマイズ項目 | 選択肢・収集要素 | ゲーム内での効果 |
| :--- | :--- | :--- |
| **アパレル・衣装パーツ** | 9部位・300種類以上 | 外見の変更 ＆ 軽微な耐性付与 |
| **武器アタッチメント** | バレル、スコープ、マガジン、トリガーなど | 反動、連射速度、怯み値の調整 |
| **アーティファクト ＆ チャーム** | 正/負の運気補正効果 | 特殊な属性ボーナスや確率発動スキルの付与 |
| **調査レポート** | 200種類以上の収集可能ログ | 敵の行動パターン、弱点、隠された設定の開示 |

200種類以上におよぶ調査レポートの収集は、単なる設定資料集めではありません。先行プレビューのフィードバックによると、アノマリーのログを読み解くことが、ミッション中の複雑な空間パズルの解法や敵のシールドを無力化する直接のヒントになります。

## 異界を生き抜くための必須サバイバル戦略

公開されている**ANOMALITH official gameplay**映像の高難度な局面を乗り越えるには、規律ある戦術的思考が不可欠です。物資の枯渇と予測不能なマップ構造に対処するため、しっかりとした準備を整えて挑みましょう。

### サバイバルの基本ステップ

1. **周辺視野・索敵を最優先:** アノマリーは天井から出現したり、ループする通路の背後にワープしてきたりします。単一の標的だけに気を取られないようにしましょう。
2. **アーティファクトのシナジーを活用:** 攻撃的な亜人化アクティブスキルと、近接フィニッシュのダメージを高めるアーティファクトを組み合わせることで、弾薬を節約できます。
3. **拠点で情報を隈なく確認:** より高難度の空間の裂け目へ出撃する前には、危険区域対策室で新しく入手した調査ファイルを必ず確認してください。
4. **空間の目印（アンカー）を意識:** 重力が反転した部屋を進む際は、非常口の標識や特徴的な血痕など、固定された環境の目印を追うことで、同じ場所を堂々巡りするのを防げます。
