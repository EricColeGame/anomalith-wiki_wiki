## ストーリー概要と世界観：アノマリーゾーンを生き延びろ

舞台は近未来、西暦20██年の日本。突如発生した局所的な現実改変現象「アノマリーゾーン（異相領域）」によって、現実そのものが崩壊を始めていました。この超常空間は重力を歪め、物理的な構造を捻じ曲げ、単に「アノマリー」と呼ばれる恐ろしい怪異を生み出します。

物語の主人公は、過酷な街を生き抜く17歳の家出少女・**皆月レオナ**。彼女は学生の**加藤アリサ**と深い絆を結んでいました。しかし、ショッピングモールを襲った突如のアノマリー化現象によってアリサが行方不明となり、レオナは真相を突き止めるため奔走することになります。親友を救出するため、レオナは政府系組織「**アノマリー対策室**」に、危険な空間の裂け目へと潜入する使い捨ての工作員「ダイバー」として志願します。


初任務において、部隊は壊滅的な損害を被り全滅の危機に瀕します。しかし、レオナは謎の超常能力を覚醒させ、これまで誰も到達できなかった深淵へと潜る重要な生存者としての道を歩み始めます。

## コアゲームプレイシステム：ダイブ、カスタマイズ、アーティファクト

本作のゲームサイクルは、危険に満ちたアノマリーゾーンへの「ダイブ（探索）」と、拠点での「戦略的準備」を交互に繰り返す構成となっています。

### 1. 空間調査と戦術的コンバット
各アノマリーゾーンには、無限に増殖する商店街や、歪んだ物理法則によって蠢く通路など、異様な環境トラップが存在します。プレイヤーは残弾数とインベントリスロットを常に意識しながら敵対的なアノマリーと交戦し、安全な脱出ポイントを確保しなければなりません。

### 2. 12種類の「アノマライズ能力」
標準的な銃火器に加え、レオナは**12種類の独自のアノマライズスキル**を使用できます。これらの能力を駆使することで、空間フィールドを操作したり、衝撃波を放ったり、深部で遭遇する特定のエリートアノマリーに対抗することが可能になります。

### 3. 奥深い装備カスタマイズ
銃器の性能は高度にカスタマイズ可能です。バレル、サイト、ストック、マガジン容量などをプレイスタイルに合わせて調整できます。さらに、危険領域から持ち帰った「**アーティファクト**」を装備することで、直接的なステータス強化やパッシブ効果を得ることができます。

| ゲームプレイ要素 | 説明 | プレイヤーの戦略への影響 |
| :--- | :--- | :--- |
| **残弾・弾薬管理** | 1回のダイブで携行できる弾薬数は有限 | 無駄撃ちを避け、正確なエイムと交戦判断を促す |
| **9部位のコスチュームシステム** | 基礎ステータスを変動させるモジュール衣装 | 見た目のファッションと実用的な防御力・速度を両立 |
| **ダイブレポート** | 敵を撃破して解放する生態ログ | 敵の弱点を特定し、世界観の理解を深める |
| **サイドミッション** | 拠点スタッフから受領する任務 | 限定クラフト素材やキャラクターのバックストーリーを獲得 |

## 『Anomalith』攻略・事前準備のポイント

発売と同時にスタートダッシュを切りたいプレイヤー向けに、トレーラーや体験版から判明した実戦的なアドバイスを紹介します：

1. **トレーラーで敵の行動パターンを予習する**: **公式トレーラー**内の戦闘シーンに注目し、敵の予備動作（テレフォンパンチ）や弱点部位の配置を把握しておきましょう。
2. **生還・脱出を最優先にする**: 先行プレイヤーの間では、レアアイテムを欲張って深追いし、高ランクのアーティファクトをロストするケースが多発しています。脱出ルートは常に早めに確保しておきましょう。
3. **9箇所の装備部位を柔軟にカスタマイズする**: 衣装は単なる見た目変更要素ではありません。9つのスロットを適切に組み合わせることで、属性耐性と機動性のバランスを最適化できます。
4. **予約特典の武器パックを活用する**: デジタルデラックス版を選択した場合、序盤から試作ハンドガンや水平二連ショットガンを使用することで、序盤特有の弾薬不足を緩和できます。
