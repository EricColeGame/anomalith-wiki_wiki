## ストーリー概要と世界観設定：19**年の「異界」

20世紀後半のもうひとつの日本（「19**年」と表記）を舞台に、「異界（Otherworlds）」と呼ばれる空間の裂け目によって引き起こされる深刻な危機が描かれます。日常の空間が敵意に満ちた不可解なリミナルスペースへと変貌する中、政府の専門組織「危険区域対策室」は対応に追われ、限界を迎えていました。

プレイヤーは、異質な建造物「サルコファガス（石棺）」の中で10年間の昏睡状態から目覚めた調査員**水無月レオナ（Reona Minazuki）**として戦いに身を投じます。超常的な知覚能力を得て目覚めたレオナは、異常現象に対する生まれつきの感受性を備えています。彼女は対策チームの仲間とともに、生存者の救出と親友の失踪の真相を突き止めるため、危険に満ちた異界への潜入任務に挑みます。

| 物語の要素 | 概要 / ゲーム内の役割 |
| :--- | :--- |
| **主人公** | 水無月レオナ。10年の昏睡を経て、異界を感知する特殊能力に目覚めた調査員。 |
| **主な舞台** | 歪んだ次元のズレとリミナルな異常現象に苛まれる「19**年」の日本。 |
| **主要組織** | 危険区域対策室。次元の脅威を調査・抑止する任務を担う。 |

| **伝承・資料** | 未知の存在や区域の生態系を解説する、200冊以上の収集可能な調査レポート。 |

## ゲームプレイメカニクス：銃撃戦、近接格闘、そして「亜人化システム」

ゲームプレイ映像から明らかなように、本作はサバイバルホラーならではの慎重なリソース管理と、スピード感あふれる三人称視点の戦闘を融合させています。予測不能な敵の行動パターンに対応するためには、戦術的なポジショニング、弾薬の残数管理、そして的確な近接アクションが求められます。

### 戦闘の流れとサバイバル要素

戦闘は、銃器で一定の距離を保ちつつ隙を伺い、無防備になった標的に接近して撃破するスタイルが基本となります。精密射撃でクリーチャーを怯ませることで、大ダメージを与える近接フィニッシャーを繰り出せます。

歪んだ環境を生き延びるには、重力が反転した部屋や無限に続く通路など、現実離れした危険現象への適応が不可欠です。

```
戦闘ループ：
[危険を察知] ➔ [距離・残弾の管理] ➔ [標的を怯ませる] ➔ [近接フィニッシャー発動] ➔ [エッセンスを採取]
```

### 亜人化（Demi-Humanization）アビリティシステム

10年間にわたり異常なエネルギーに晒されていたレオナは、撃破した異形の怪物から直接、固有のアクティブスキルやパッシブ効果を吸収することができます。この**亜人化システム**により、ステルス重視、攻撃的な近接型、あるいは遠距離武器特化など、プレイヤーの好みに合わせたビルド構築が可能です。

| システム / 機能 | メカニクスとプレイヤーへの影響 | 戦略的価値 |
| :--- | :--- | :--- |
| **三人称視点の銃撃戦** | 予測不能に動く敵の行動パターンに対する精密な照準射撃。 | 中〜長距離の脅威を安全に排除。 |
| **スタン＆近接フィニッシャー** | 敵性存在を怯ませた後に繰り出す強力な物理攻撃。 | 銃器の弾薬を節約可能。 |
