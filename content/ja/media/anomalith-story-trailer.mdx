## 世界観と設定：歪んだ「異界」への潜入

プロモーション映像で提示された物語は、レトロフューチャーで不気味な恐怖に満ちた設定となっています。20世紀後半（19**年）の某年、世界は「異界」と呼ばれる突発的な現実の崩壊に見舞われます。これらの空間異常は物理法則を無視し、日常的な建造物をシュールで危険な構造物へと変貌させてしまいます。

政府の専門防衛組織である「危険地帯対策室」は圧倒的な事態に翻弄され、この空間裂け目の発生源を特定できずにいます。プレイヤーは、謎めいた特異点「サルコファガス（石棺）」の中で10年間の眠りから目覚めたエリート調査員、水無月レオナの視点でプレイすることになります。

| 設定要素 | 説明 | 物語上の役割 |
| :--- | :--- | :--- |
| **異界** | 敵対的存在が巣食う、現実が歪められた空間ポケット。 | メインミッションの舞台およびダンジョン環境。 |
| **危険地帯対策室** | 異常事態の封じ込めを担当する政府機関。 | レオナの所属先であり作戦本部（ハブ）。 |
| **サルコファガス（石棺）** | レオナが10年間収容されていた謎の特異点。 | レオナの持つ不可解な超常能力の源。 |
| **水無月レオナ** | 異常現象に対する感覚的適性を備えた、目覚めた調査員。 | 親しい友人を救うため行動するメイン主人公。 |
| **調査報告書** | ステージ内に散りばめられた200冊以上の収集型資料。 | 世界観の構築および敵の弱点情報の記録。 |

長期にわたる隔離の影響で、レオナはこれらの異質な空間に対して特異な感受性を示します。彼女の個人的な目的は単なる政府任務にとどまりません。世界の崩壊を防ごうとしながらも、かけがえのない仲間を救い出すために空間の裂け目へと足を踏み入れます。

## コアゲームプレイとサバイバルシステム

本作の根本はサバイバルTPS（三人称視点シューター）であり、エイム力と同じくらいリソース管理が重要となります。上下逆さまの集合住宅や終わりのない通勤列車といったリミナルスペースには、不規則に動く飢えた怪異が徘徊しており、迅速な状況判断が求められます。

映像では、流れるような銃撃戦と、敵が怯んだ（スタン）際に繰り出す強力な近接フィニッシャーの組み合わせが強調されています。生き残るためには、インベントリを細かく管理し、残弾数に気を配り、空間上の危険ギミックを巧みに利用しなければなりません。

```
[怪異と交戦] ➔ [射撃でスタン値を蓄積] ➔ [強力な近接フィニッシャーを発動] ➔ [怪異のエッセンスを抽出]
```

### 亜人化システム（Demi-Humanization System）

ゲームプレイ概要で注目を集めたシステムの一つが「亜人化システム」です。レオナが持つ空間裂け目との生来の繋がりを利用し、撃破した怪異から異質な特性を吸収することで、多彩なアクティブ戦闘スキルやパッシブ生存パークをアンロックできます。

| システムカテゴリ | メカニクスと効果 | 戦術的用途 |
| :--- | :--- | :--- |
| **アクティブ異界能力** | 念動力バースト、位相回避、感覚スキャンなど。 | 狭い通路からの脱出や敵のガード崩し。 |
| **パッシブ変異** | 弾薬所持数増加、近接攻撃力強化、音響トラッキングなど。 | 長期的なダンジョン探索での生存およびリソース節約。 |
| **スタンシステム** | 高威力の射撃により敵を行動不能にし、処刑攻撃を可能にする。 | 近接攻撃で仕留めることによる弾薬の節約。 |
| **グリッド式インベントリ** | 医療キット、弾薬箱、遺物の携行数に上限が存在。 | 異界へ突入する前の戦略的な装備計画が必要。 |

### ゲーム内で武器や衣装のカスタマイズは可能ですか？
