## 『Anomalith』デモトレーラーで明かされたストーリーと世界観設定

西暦20██年のパラレルワールドの日本を舞台にした『ANOMALITH』では、突如として日常の街並みを引き裂くように出現した奇怪かつ危険なアノマリー（異常空間）に立ち向かうことになります。物語の主人公は17歳の平凡な女子高生、水無月レオナ。大型ショッピングモールで発生した大惨事によって、彼女の日常は一変します。親友が突如現れた異空間の狭間へと姿を消したことをきっかけに、レオナは政府管轄の「アノマリーゾーン対策室」に正式な「ダイバー」として志願・所属することになります。

```
ショッピングモール事件 (20██年) ➔ ゾーン出現 ➔ レオナがダイバーとして入隊 ➔ 異能の覚醒 ➔ 深淵の探索へ
```

**anomalith demo trailer**で描かれるトーンは重厚でダークな雰囲気に満ちており、ダイバーたちが任務中に日常的に命を落とす過酷な世界を浮き彫りにしています。初ダイブの際、レオナは部隊が全滅する過酷な状況から奇跡的に生還し、アノマリーの力を利用した戦闘能力を目覚めさせます。親友を救出すること、そして政府がひた隠しにする現象の真相を暴くため、彼女は強い決意を胸にアノマリーの深淵へと潜っていきます。

## コアゲームプレイループ：ダイブ・回収・帰還

『ANOMALITH』のゲームプレイの根幹は、ハイテンポな三人称視点シューティング（TPS）と、適度な緊張感を持つ脱出系（エクストラクション・ライト）サバイバル要素の融合です。ミッションに向けて出撃準備を整えたプレイヤーは、立ち回り、弾薬管理、脅威度の見極めが生死を分ける予測不能な次元ゾーンへと足を踏み入れます。

```
出撃準備（ワークショップで装備編成） ➔ 潜入（ゾーンへのダイブ） ➔ アノマリー戦闘と素材回収 ➔ セーフゾーンへの帰還・脱出
```

基本的なサイクルは以下の3段階で進行します：
1. **ダイブ（Dive）**：重力が歪み、シュルレアリスム的な建築が広がり、「アノマリー」と呼ばれる異形の怪物が徘徊する不安定ゾーンへ突入。
2. **回収（Retrieve）**：弾薬の過剰消費を避けながら、貴重な異常遺物（Anomalous Objects）、武器設計図、クラフト素材を探索・回収。
3. **帰還（Return）**：空間の崩壊や環境の不安定化に呑み込まれる前に、指定された脱出地点へ到達して生還。

## ダイバー志望者のための戦術アドバイス

**anomalith demo trailer**で明かされた戦術メカニクスやコミュニティの検証結果に基づき、ダイブを生き残るための重要ポイントをまとめました。

* **大口径弾薬を温存する**：スナイパーライフルの弾薬は高脅威度のエリートアノマリー戦用にキープしましょう。道中の雑魚敵にはサイドアームや近接攻撃で対処するのが基本です。
* **脱出マーカーを常に意識する**：レア素材がドロップすると欲張りがちですが、脱出タイマーを逃すと空間崩壊に巻き込まれて全滅してしまいます。
* **シューティングチップを早期に強化する**：火力アップ系チップを優先して装備することで、シールドを持つアノマリーの撃破時間を大幅に短縮できます。
* **音の予兆を聞き逃さない**：不安定ゾーンでは環境音が変化します。高周波のノイズや歪み音は、敵の奇襲や空間の裂け目（リフト）が発生する予兆です。

各種プロモーション映像や躍動感あふれる**anomalith demo trailer**が示す通り、空間の把握力と素早い装備マネジメントを極めることこそが、20██年の異変の真実へとたどり着くための鍵となります。
