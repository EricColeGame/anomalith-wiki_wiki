## 難易度スケーリングと隠し仕様の理解

ゲーム内で難易度を切り替える際、システム側では内部で何が実際に変化しているのかについての説明は最小限しか表示されません。コミュニティの報告やプレイヤーによる詳細な検証に基づくと、難易度設定によってタイミングの受付時間が大幅に変更されることはありませんが、許容されるミスの範囲（マージン）は劇的に狭まります。

高難易度になると視覚的なインジケーターを完全に削除してしまうゲームとは異なり、本作ではすべての難易度で主要な視覚的手がかりが維持されます。敵は依然として光るエフェクトで攻撃を予兆（テレグラフ）し、基本的なパリィ受付時間も比較的安定しています。本当のプレッシャーは、HPが常に危険に晒されている状況下で、ミスに対するペナルティが極めて重くなることから生じます。

| 難易度要素 | スタンダード / ノーマルモード | Anomalith ハードモード | 戦術的な影響 |
| :--- | :--- | :--- | :--- |
| **敵の与ダメージ** | 中程度（3〜5回被弾で死亡） | 高（1〜2回の被弾で致命傷） | 近接距離でのミスが致命的な結果を招く。 |
| **敵の体力（HPプール）** | 基準値（ハンドガンHS 3〜4発） | やや増加 / より頑丈な敵 | 弾薬を節約するため厳格なヘッドショット精度が必須。 |
| **1発あたりのMP生成量** | 命中時に素早く回復 | 一定の回復率を維持 | 銃撃を維持することでアノマリーパワーを継続利用可能。 |
| **攻撃予兆の光（テレグラフ）** | 明るい攻撃インジケーター | 明るい攻撃インジケーター | タイミングさえ合わせればパリィは十分可能。 |
| **回復アイテムのドロップ** | 定期的に回復アイテムが出現 | リソース配置が非常に乏しい | MPのためにHPを削る行為が極めて危険になる。 |

これらの根本的な要因を理解しておくことで、よくある誤解を防ぐことができます。パリィのタイミングを一から覚え直す必要はありません。その代わりに、狭い空間で敵に圧倒されないよう、攻撃の手数を最適化することが求められます。

## アノマリーMPエコノミーと戦闘ループの習得

**Anomalith ハードモード**で生き残るための要となるのは、通常の銃器使用とアノマリーパワーとの動的なバランスを理解することです。キャラクターの鉤爪攻撃や特殊能力にはマナポイント（MP）が必要であり、これは銃器と直接連動した循環型のエコノミーで機能しています。

[ANOMALITH Steam コミュニティハブ](https://steamcommunity.com/app/4017880/discussions/)のディスカッションでも、高難易度においてアノマリーパワーがどれほど強力であり続けるかが強調されています。ハンドガンで正確に数発ヒットさせるだけで、MPゲージを完全に満タンにすることが可能です。これにより、「銃撃でMPを溜め、高威力のアノマリー攻撃を叩き込んで余計な弾薬を消費せずに素早くターゲットを排除する」という自然なリズムが生まれます。

```
[ 銃器ダメージ / 精密射撃 ]

               ▼
     [ 素早いMP自動回復 ]

               ▼
   [ 強力なアノマリー鉤爪攻撃 ] 
               │
               ▼
     [ 敵の撃破 / 状況リセット ]
```

### HPからMPへの変換：実行する価値はあるか？

本作には、HPを犠牲にして即座にMPを獲得できる内部メカニクスが存在します。この機能は弾薬が完全に底をついた際の絶望的な命綱となりますが、プレイヤーの経験上、高難易度の戦闘ではこの変換を可能な限り避けることが推奨されます。

| リソース変換方式 | メリット | デメリット | ハードモードでの推奨度 |
| :--- | :--- | :--- | :--- |
| **銃撃からMPへ** | 最も安全な方法。距離を維持可能で弾1発あたりの獲得量が高い。 | 限られたハンドガン弾薬を消費する。 | **基本戦術**：3〜4発のヘッドショットを当ててMPを最大まで溜める。 |
| **HPからMPへの犠牲** | 弾を撃たずに即座にアビリティを発動可能。 | 貴重なHPを消費し、一撃死圏内に追い込まれる。 | **緊急時のみ**：弾薬が完全に枯渇した場合にのみ限定使用。 |
| **鉤爪による処刑** | 弾薬コストゼロ。単体に対して壊滅的なダメージ。 | 近接戦への飛び込みと隙（リスク）が生じる。 | **主力フィニッシャー**：銃撃で怯ませた後に追撃として使用。 |

回復アイテムが希少であるため、**Anomalith ハードモード**の攻略中に意図的にHPを減らすと、敵の何気ない一撃による即死リスクに晒されることになります。HP変換機能は通常の戦闘ローテーション用ではなく、あくまで最終手段の緊急回避策として扱いましょう。

## 移動の最適化と操作設定

致命的な攻撃を回避し、最適な間合いを維持する上で、移動の滑らかさは極めて重要な役割を果たします。本作には、キャラクターのレスポンスに大きく影響を与える複数の操作設定が用意されています。

プレイヤー検証から判明した極めて重要な発見の一つが、「常時ダッシュ（Always Run）」設定とスプリントキー長押しの違いです。手動スプリントを使用している場合、構え状態からダッシュへ移行する際にわずかな遅延（ディレイ）が発生します。デフォルトの移動モードを切り替えることで、この挙動を直接改善できます。

| 移動設定 | 入力挙動 | 戦闘上のメリット | 潜在的なデメリット |
| :--- | :--- | :--- | :--- |
| **デフォルト歩き（Shiftで走る）** | 通常は歩き移動。エイム後に走るにはスプリントキーの長押しが必要。 | 崖際や狭い角での正確な微調整位置取りが可能。 | エイムからダッシュへの移行にわずかな遅延が発生し、回避が難しくなる。 |
| **常時ダッシュ（デフォルト走り）** | 方向入力をするだけで自動的にダッシュする。 | エイム解除後に即座に再配置可能。攻撃の回避が容易になる。 | スプリントキーによる切り替えの利便性が失われ、操作が過剰に機敏に感じられることがある。 |
| **戦術的リポジショニング** | エイム解除と同時に素早く方向入力を行う。 | 敵の攻撃モーション完了前に追尾（トラッキング）を振り切る。 | 武器を構え直す速度を管理するための慣れ（マッスルメモリー）が必要。 |

生存率を最大限に高めるには、デフォルト状態を「走り」に設定し、近接交戦から離脱する際のラグをなくすのが有効です。この一瞬の差が、敵の攻撃が直撃するか空振りに終わるかの決定打となります。

## 防御メカニクス：パリィ、攻撃予兆、間合い管理

防御とは単に後ろに下がるだけではなく、戦闘の流れを支配することです。ゲーム内の敵は、攻撃判定が発生する直前に特徴的な光る視覚的合図（テレグラフ）を発します。

一部のプレイヤーはこの攻撃予兆の強い発光演出を派手すぎると感じるかもしれませんが、**Anomalith ハードモード**をプレイする上では、これを戦術的に利用することが極めて重要です。骨太なソウルライク系タイトルと比較するとパリィの受付時間は寛容に設定されているため、視覚的な確認からカウンターを狙う技術を身につけることで、戦闘を圧倒的にコントロールしやすくなります。

| 防御戦術 | 入力タイミング | リワード | リスクレベル |
| :--- | :--- | :--- | :--- |
| **フラッシュパリィ** | 敵の発光が表示された瞬間にボタンを入力。 | 敵が即座に体勢を崩す。隙だらけの相手に鉤爪攻撃を叩き込める。 | 高（タイミングを逃すと大ダメージを受ける）。 |
| **バックスステップ間合い管理** | エイムを解除し、まっすぐ後方へ移動。 | パリィミスのリスクを負わずに攻撃判定エリアから完全に脱出。 | 低（モーションの遅い攻撃に対して安全）。 |
| **能動的な怯ませ（スタッガー）** | 敵の攻撃準備中にハンドガンで素早く頭部へ2発撃ち込む。 | 攻撃判定が発生する前に敵の攻撃アニメーションを中断させる。 | 中（プレッシャー下での正確なエイムが必要）。 |

### 交戦時のステップバイステップ手順

1. **索敵と状況判断：** 接敵する前に敵の種類を特定し、部屋内での十分な距離を確保する。
2. **ヘッドショットで弱体化：** 頭部のヒットボックスに正確に2〜3発撃ち込み、怯ませを発生させつつMPゲージをチャージする。
3. **発光サインの見極め：** 敵が距離を詰めてきたら攻撃の発光を注視し、パリィまたはバックステップを実行する。
4. **アノマリークローの発動：** チャージしたアノマリーアビリティを放ち、即座にターゲットを仕留める。
5. **アイテム回収と再配置：** 周辺を探索してドロップした弾薬を回収し、次の部屋へ進む前に体勢と位置取りをリセットする。

## 武器とリソースの優先順位ガイド

リソースの節約は、攻略の成否を分ける決定的なスキルです。敵のタイプごとにどれだけの弾薬を消費すべきかを把握しておくことで、激しい連戦に備えて健全な弾薬備蓄を維持できます。

| 対象となる敵タイプ | 主力武器の選択 | 推奨されるMPアビリティ使用法 | 目標弾薬消費量 |
| :--- | :--- | :--- | :--- |
| **通常徘徊型（Roamer）** | ハンドガン（ヘッドショット） | とどめの鉤爪攻撃 | ハンドガン弾 最大3〜4発 |
| **俊足追跡型（Stalker）** | ハンドガン / パリィ | 即座にアノマリークロー | ハンドガン弾 2発 + パリィ 1回 |
| **大型重装型（Brute）** | ショットガン / 大口径武器 | 多段ヒットのアノマリー連打 | 重火器 2発 + MP全消費攻撃 |
| **奇襲集団（Ambush）** | 距離確保 / クラウドコントロール | 可能であればアノマリー範囲攻撃 | ショットガン弾を温存し、ハンドガンを優先 |

これらの弾薬消費目安を守ることで、突発的な難易度の上昇に直面してもリソース切れに陥るのを防ぐことができます。「射撃→鉤爪」のループを一貫して実行することで、**Anomalith ハードモード**の攻略全体を通じて弾薬の消耗を最小限に抑え、素早く敵を殲滅することが可能になります。

## よくある質問（FAQ）

### Anomalithのハードモードは通常難易度と何が違いますか？
視覚的な攻撃予兆やパリィの受付時間といった基本システムは同等ですが、敵の攻撃力が大幅に増加し、敵の体力もわずかに上昇し、回復アイテムの配置数が大幅に減少します。生き残るには、徹底した弾薬管理とアノマリーアビリティの最適な活用が不可欠です。

### ハードモードではパリィの受付時間が短くなりますか？
コミュニティの検証やプレイヤーの報告によると、パリィの受付時間は難易度を問わず比較的寛容なまま維持されています。主な違いはパリィ失敗時のペナルティであり、高難易度では敵から受けるダメージが極めて高くなります。

### 厳しい戦闘局面でMPを維持するにはどうすればよいですか？
MPは銃器の弾を敵に命中させることで急速に回復します。通常、ハンドガンで頭部に3〜4発ヒットさせればMPバーは完全に満タンになるため、貴重なHPを犠牲にすることなく強力な鉤爪攻撃を繰り出すことができます。

### HPをMPに変換する機能は使うべきですか？
原則としておすすめしません。回復アイテムが乏しく敵の攻撃力が高いハードモードでは、HPをMPに変えると一撃死のリスクが非常に高くなります。HP変換は、弾薬が完全に尽きてしまった場合の緊急避難手段としてのみ使用してください。
