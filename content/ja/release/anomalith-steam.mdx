## 『ANOMALITH』とは？ストーリーと世界観

舞台は20██年のパラレルワールドの日本。国内各所で前触れもなく超自然的な「変異区域（Anomaly Zones）」が出現し始めます。この異常な侵食現象によって日常的な空間は歪み、リミナルスペースの悪夢と化した区域には、「アノマリー（Anomalies）」と呼ばれるグロテスクで敵対的なクリーチャーが徘徊するようになりました。

物語の主人公は、17歳の女子高校生「水無月 怜央奈（みなづき れおな）」。ショッピングモールでの買い出し中に突如発生した変異現象に巻き込まれ、親友の「加藤 有紗（かとう ありさ）」と離れ離れになってしまいます。友人の失踪を受け入れられない怜央奈は、政府公認の「変異区域対策室」に所属する正規の「ダイバー」として志願することを決意します。

| **物語の核心** | 変異区域の突如の出現と、怜央奈自身の超常能力の覚醒。 |

最初の探索任務中、歴戦のダイバーたちが区域の恐怖に屈していくのを目撃した怜央奈は、自らに眠る戦闘能力を覚醒させます。専用装備と異能の戦闘スキルを手に、彼女は変化し続ける区域の奥深くへと潜り、自身の力に秘められた真実を突き止め、有紗を救出するための戦いに身を投じます。

## コアゲームシステム：「ダイブ・回収・帰還」のサイクル

本作の根幹は、**「ダイブ（潜入）」「回収」「帰還」**という厳密なループを中心に据えたサバイバルアクションRPG／三人称視点シューティングです。生き残るためには、各区域に入る前の入念な準備と、探索中における徹底したリソース管理が求められます。

```
[装備の準備] -> [変異区域へダイブ] -> [アノマリーとの戦闘＆物資回収] -> [無事に脱出] -> [装備強化＆工房拡張]
```

### 1. 戦術的な三人称視点（TPS）コンバット

アノマリーとの戦闘は、単なる撃ち合い（ラン＆ガン）ではありません。プレイヤーは銃器による射撃と、攻撃・防御に特化した「変異スキル」を臨機応変に使い分ける必要があります。限られた弾薬の管理、近接特化のショットガンと精密狙撃ライフルの選択、そして閉所や入り組んだ通路での空間把握能力が生死を分けます。

### 2. 奥深い装備クラフトと外見カスタマイズ

探索で回収したアイテムやアノマリーの破片、各種素材は拠点となる工房へ持ち帰ることができます。伏見伊万里の研究ラボでは、新たな銃器の作成、基礎ステータスの強化、特殊なサバイバルガジェットの開発が可能です。さらに重要な点として、外見変更（コスメティック）システムにより、装備の性能を維持したまま怜央奈の衣装や装備の見た目を自由に変更できます。防御力を犠牲にすることなく、好みのスタイルで探索を楽しめます。

| 戦闘＆サバイバルシステム | 戦略的な目的 | プレイヤーの判断ポイント |
| :--- | :--- | :--- |
| **弾薬の節約** | 区域内の補給物資は極めて貴重。 | 銃器の精密射撃と近接・スキルの使い分け。 |
| **変異スキル** | 攻撃バーストや防御バリアを展開可能。 | 敵の大群に囲まれた際のクールダウン管理。 |
| **脱出システム** | 指定の脱出地点に到達して戦利品を確保。 | さらなる深部探索のリスクと現在の報酬確保の天秤。 |
| **外見変更（幻化）** | 装備性能を損なわずに見た目をカスタマイズ。 | ダイバーのビジュアルを自分好みに完全調整。 |
