## ストーリー概要：変異領域からの生還

舞台は20██年の近未来の日本。都市部に突如として壊滅的な「変異領域（アノマリーゾーン）」が出現し、現実世界が崩壊し始めます。政府は現実を歪めるこの空間の調査、封じ込め、そして物資回収を行うため「変異領域対策室」を設立しました。

プレイヤーは、親友が変異領域内へと姿を消したことをきっかけに「ダイバー」を志願した17歳の少女、**水無月レオナ（Reona Minazuki）**として戦いに身を投じます。しかし過酷な初ダイブの最中、レオナの部隊は「アノマリー」と呼ばれる未知の異形生物によって全滅してしまいます。

唯一の生存者となったレオナは、体内に眠っていた超常的な変異能力に覚醒。銃火器と進化する特殊能力を手に、親友の失踪の真相、自身の身体に起きている異変、そしてアノマリーの起源を解き明かすため、深淵なる領域の奥深くへと挑みます。

本作のゲームサイクルは、極限の緊張感の中で展開される**「潜入・回収・帰還（Dive, Retrieve, Return）」**のエクストラクションループをベースにしています。プレイヤーは限られた物資を管理し、刻一刻と変化する環境に対応しながら、極限状況下で的確な戦術的判断を下さなければなりません。

```
[変異領域へ潜入] ➔ [戦闘＆物資回収] ➔ [脱出地点の特定] ➔ [拠点強化＆装備調整]
```

### 変異領域の探索メカニクス

領域内の環境は物理法則を無視しており、見慣れた都市空間が歪んだ空間パズルへと変貌しています。

* **重力反転複合施設：** 床、壁、天井が動的に入れ替わる団地・マンション内を立体的に探索。
* **蠢く回廊：** 銃撃戦の最中にねじれ、伸び、射線を遮るように変形する屋内通路。
* **無限増殖商店街：** 無限に複製され続ける商店街。マーカーを頼りに進み、無限ループの罠を回避。

## 初心者向け攻略ガイド：ダイブを生き抜くための心得

変異領域の過酷な環境を攻略するには、正しい立ち回りを身につけることが重要です。**『ANOMALITH』Switch 2版**で生き残るための基本ルールをご紹介します。

1. **戦闘よりもルート選定を優先する：** 一般的な敵をすべて倒しても追加ボーナスはありません。弾薬の消耗が激しい戦闘は、脇道を使って回避するのが鉄則です。
2. **インベントリの空きを確保する：** 出撃時は常に最低4スロット以上の空きを残しておきましょう。基本物資でバッグを満杯にしてしまうと、脱出直前で見つかる貴重なアーティファクトを持ち帰れません。
3. **スキルの回転率を意識する：** レオナの12種類の変異スキルは、緊急回避用だけでなく攻撃の起点としても機能します。敵を足止めするスキルと至近距離のショットガンを組み合わせることで、素早く敵を殲滅できます。
4. **ダイブログを熟読する：** 倒した異形の生態データは拠点のアーカイブに記録されます。属性の弱点を事前に把握しておくことで、戦闘時間を大幅に短縮できます。

**『ANOMALITH』Switch 2版**の深部へ潜る前に、これらの基本をしっかりと押さえておくことで、貴重な装備を失うリスクを最小限に抑えられます。
