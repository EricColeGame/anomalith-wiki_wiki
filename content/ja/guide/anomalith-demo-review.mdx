## 『ANOMALITH』とは？ 世界観と基本ストーリー

『ANOMALITH』の舞台は、20██年のパラレルワールドの現代日本。「異常領域（Anomaly Zone）」と呼ばれるシュールな異次元空間が突如として現実を侵食し始めます。物語は、主人公の水無月レオナが親友の加藤アリサとショッピングモールを訪れていたところから始まります。そのモールが突如「アノマライゼーション（異常化）」に巻き込まれ、周囲の環境は崩壊、2人は離れ離れになってしまいます。

事件から生還したレオナは、政府系組織である「異常領域対策室」のダイバーに志願し、アリサを救出するため再び超常の裂け目へと足を踏み入れます。最初のダイブの最中、彼女の中で異常な力（アノマライゼーション）が覚醒し、部隊のダイバーたちが全滅する中で唯一の生存者となります。

## ゲームプレイシステム：「ダイブ・回収・帰還」のサイクル

『ANOMALITH』の根本的な魅力は、サバイバルホラーの緊張感とサードパーソンシューティング、そして軽快な脱出（エクストラクション）要素を組み合わせたリソース管理にあります。ゲームプレイは、**「ダイブ・回収・帰還」**という厳格なサイクルを中心に展開します。

```
[ ワークショップで準備 ] ➔ [ 異常領域へ出撃 ] ➔ [ 戦闘＆物資の探索回収 ] ➔ [ 脱出地点へ到達 ] ➔ [ 武器のクラフト＆強化 ]
```

### 1. 戦闘とアノマライゼーションスキル
戦闘では常に周囲の状況把握が求められます。プレイヤーはハンドガン、ショットガン、セミオートライフルなどの銃器と、**アノマライゼーションスキル**と呼ばれる超常能力を切り替えて戦います。これらのアクティブスキルは、狭い通路で攻撃的なアノマリー（異形）に囲まれた際のクラウドコントロール（敵の足止め）や防御手段として不可欠です。

### 2. リソース管理とインベントリ運用
一発一発の弾薬が貴重です。無闇に乱射すると、あっという間に限られた弾薬が底をついてしまいます。プレイヤーは鎮静剤や医療品などの必須消耗品と、アノマリーから回収した生のクラフト素材との間でインベントリの空き容量を適切にやりくりする必要があります。

### 3. 装備の強化とファッションカスタマイズ
異常領域対策室に持ち帰った戦利品は、伏見いまりに渡すことで装備の合成に使用できます。武器のステータス強化、新たな射撃チップの解放、衣装の自由な変更が可能です。嬉しい要素として、見た目のカスタマイズ（重ね着）はステータスから完全に独立しているため、自分好みのファッションで高難度のダイブに挑むことができます。

### 主要ゲームプレイ要素の内訳

| 機能 | 主な役割 | 戦術的な影響 |
| :--- | :--- | :--- |
| **サードパーソンシューティング** | 物理的なアノマリーに対する基本攻撃手段 | 弾薬の節約と正確な弱点射撃が必須 |
| **アノマライゼーションスキル** | 超常的な攻撃・防御アビリティ | ボス戦などで戦況を覆すための切り札 |
| **脱出（エクストラクション）メカクス** | 回収した物資を持って無事に生還する | 失敗すると回収した研究素材をロストするリスク |
| **ワークショップクラフト** | 銃器の強化とバトルチップの生成 | 基礎生存ステータスや属性ダメージの底上げ |
| **外見変更（トランスモグ）** | 衣服や装備のビジュアルを変更 | 戦闘ステータスに影響を与えない純粋な見た目変更 |

## 体験版インプレッション：長所・短所と総評

試遊版をじっくりプレイしてみると、開発チームの明確なこだわりが見えてきました。本**anomalith demo review**（体験版レビュー）のこのセクションでは、優れている点と製品版に向けて改善が期待されるポイントを整理します。

プレイヤーの反応や当メディアの実機プレイから言えるのは、リミナルスペース特有のレトロな美学が見事に表現されている点です。人気のないタイルの商店街、薄暗いデパートの地下、不気味にハミングする蛍光灯など、昭和の建築様式が安易なジャンプスケア（ビックリ演出）に頼ることなく、本格的な心理的恐怖を生み出しています。

### 体験版の良かった点（ストロングポイント）
- **雰囲気抜群のサウンドデザイン：** 北村友香氏によるアンビエントな劇伴が、恐怖感を最高レベルに引き上げている。

### 改善が期待される点
- **狭所でのカメラワーク：** モールの狭い通路で大型のアノマリーに追い詰められた際、三人称視点のカメラが窮屈になることがある。
