## 概要：手術室での戦闘詳細

手術室は、散乱した医療器具、手術用ランプ、狭い射線に囲まれた極度の緊張感が漂うエリアです。敵を誘導しながら戦えたこれまでの小競り合いとは異なり、この戦いでは近〜中距離での素早い反応速度が求められます。

| 戦闘データ | 詳細 |
| :--- | :--- |
| **出現場所** | 廃棄病棟 – 第3手術室 (Operating Room 3) |
| **ボスタイプ** | 変異肉体織り手 (Aberrant Flesh-Weaver) / 高速連撃型 |
| **主なダメージ属性** | 斬撃、神経毒 / 正気度減少 (Sanity Decay) |
| **弱点部位** | 露出した脊髄結節、隙を晒した際の胸部コア |
| **推奨レベル / 装備ランク** | ティア3サバイバルギア / 強化サイドアーム |
| **想定戦闘時間** | 4〜7分 |

勝利するためには、スタミナ管理だけでなくメンタル安定度ゲージ（正気度）の維持も不可欠です。ボスの近くに長時間留まると持続的なパッシブデバフを受けるため、常に位置取りへの警戒を最優先に立ち回りましょう。

## フェーズ別詳細攻略

この戦闘は3つの異なるフェーズで進行し、後半になるほど凶暴性を増します。フェーズ移行のトリガーとなる体力は70%と35%です。

```
[フェーズ1: 100% - 70%] ──> [フェーズ2: 70% - 35%] ──> [フェーズ3: 35% - 0%]
  規則的な斬撃攻撃             天井からの奇襲               怒り狂う猛攻
  エリア内の位置取り           正気度への危険ギミック       パリィ不可の広範囲薙ぎ払い
```

### フェーズ1: 計算されたメス (HP 100% – 70%)

開幕フェーズでは、不気味なほど優雅な動きを見せます。主に伸ばした手術器具のような四肢による広範囲の水平スイングを多用してきます。

| 攻撃名 | 視覚 / 音声の予兆 | 回避方向 | 反撃の隙 |
| :--- | :--- | :--- | :--- |
| **サージカル・クリーヴ (Surgical Cleave)** | 右手の刃を頭上に掲げる。金属的な擦過音 | 後方へ2回連続ステップ | 1.5秒（左側面に回り込む） |
| **ブリンク・ランジ (Blink Lunge)** | 影の中に姿を消す。床が光る | 足音が聞こえた瞬間に横ローリング | 2.0秒（背後の結節を攻撃） |
| **ニューロトキシン・ミスト (Neurotoxin Mist)** | 胸腔から紫色の蒸気を噴出 | 即座に距離を取る | 遠距離武器での射撃のみ |

中央の手術台を囲むように中距離を維持しましょう。ボスが「ブリンク・ランジ」を繰り出してきたら、すかさず右側へローリングし、長い硬直時間にメイン火器で手痛い反撃を与えてください。

### フェーズ2: 上空からの急襲と環境の脅威 (HP 70% – 35%)

HPが70%まで削られると、ボスは金切り声を上げて天井の手術用照明レールへと飛び移ります。エリア内の照明が点滅を始め、視界が大幅に悪化します。

1. **天井の動きを追跡する:** 天井パネルから落ちる埃の粒子や、移動する影の動きを注視してください。
2. **急降下攻撃を回避する:** ボスが真下にダイブすると、半径5メートルに衝撃波が発生します。外側へダッシュし、地面の揺れをジャンプまたはステップでかわしましょう。
3. **周囲の結節を破壊する:** ボスが空中にいる間、壁に脈打つ肉の嚢胞が出現し、プレイヤーの正気度を奪います。ピストルを1発当てて素早く破壊してください。

| フェーズ2のギミック | 危険度 | 対処方法 | 放置した場合のペナルティ |
| :--- | :--- | :--- | :--- |
| **胞子嚢胞 (Spore Cysts)** | 中 | 高精度ピストル1発で破壊 | 画面の継続的な歪みとエイムブレ |
| **散乱したガラス片** | 低 | 破片の上を歩かない | よろめき発生およびボスへの位置露見 |
| **オーバーヘッド・スラム (Overhead Slam)** | 致命的 | タイミングを合わせた横ダッシュ＋回避 | 即死または重度の致命傷 |

### フェーズ3: 狂乱の猛攻 (HP 35% – 0%)

**Anomalithボス戦**の最終局面に入ると、怪物は一切の防御姿勢を捨て去ります。永続的な狂乱状態となり、中央リング一帯に腐食液を撒き散らしながら素早い多段ヒットコンボを繰り出してきます。

| ボスの行動 | 対処戦略 | リスク要因 |
| :--- | :--- | :--- |
| **4連撃乱舞 (Quad-Combo Flurry)** | 後退しつつ、2段目と4段目の攻撃に合わせて回避ローリング | 極めて高い（確定ダウン） |
| **強酸の排出 (Acid Discharge)** | 中央リングには立ち入らず、必ず外壁沿いに陣取って戦う | 高（アーマーの急速劣化） |
| **デスペレーション・グラブ (Desperation Grab)** | 赤く光る胸部コアを確認し、高よろめき値の弾を直接撃ち込む | 致命的（一撃必殺の処刑攻撃） |

このフェーズでは、欲張った近接連続攻撃や悠長なリロードは厳禁です。瞬間火力を重視し、ボスの3段コンボを誘い出してから、露出した胸部コアに集中砲火を浴びせて一気に決着をつけましょう。

## よくある質問（FAQ）

### Anomalithボス戦に最もおすすめのビルドは？
コミュニティの検証結果では、機動力を重視したビルドに瞬間火力の高いショットガンと正気度安定化チャームを組み合わせるのが最も戦いやすく、短い攻撃チャンスを的確に活かすことができます。

### 手術室での正気度（Sanity）ゲージの減少を止めるには？
戦闘前に「ニューロアンカー」のトリンケットを装備しておくと、正気度の減少速度が劇的に低下します。また、フェーズ2で壁に出現する光る嚢胞を素早く撃ち落とすことで、正気度の大幅な低下を防げます。

### Anomalithボス戦で敵の攻撃をパリィすることはできますか？
フェーズ1における標準的な単発の刃による斬撃のみ、精密なタイミングでパリィが可能です。多段ヒット乱舞、突進、フェーズ3の狂乱薙ぎ払いはすべてパリィ不可となっているため、回避するか間合いを取って対処してください。
