踏入充滿異界威脅的超現實日式閾限走廊，需要敏銳的反應與明智的資源規劃。核心的 **anomalith gameplay** 循環結合了第三人稱射擊的精準度與撤離玩法的緊張感，讓 17 歲的主角水名月玲緒奈（Reona Minazuki）勇闖詭異的異常區域（Anomaly Zones）。為了在這些難以預測的侵蝕中存活並揭開好友失蹤的真相，在展開第一次撤離任務前，掌握 **anomalith gameplay** 的基礎機制至關重要。

無論你是在探索奇異變幻的昭和風建築，還是與可怖的實體交戰，這份全方位的生存指南都將為你解析所有必備的遊戲機制、裝備成長路線與戰術戰鬥策略。

## 核心玩法循環：潛入、回收與返回

遊戲的核心建立在高風險的三階段循環之上：潛入危險區域、獲取異常物質，並活著抵達撤離點。與傳統的線性動作遊戲不同，每一次出擊都需要經過精打細算的風險管理。

```
[ 進入異常區域 ] ➔ [ 探索與戰鬥 ] ➔ [ 收集異常物件 ] ➔ [ 撤離 / 工作室 ]
```

當你進入一個分區時，主要目標是在完成任務條件的同時收集珍貴資源。然而，逗留過久會增加被名為「異常體（Anomalies）」的敵對生物包圍壓制的風險。

### 潛入階段解析

| 潛入階段 | 核心目標 | 風險等級 | 主要行動 |
| :--- | :--- | :--- | :--- |
| **滲透（潛入 / Dive）** | 突破目標分區 | 低至中等 | 偵察入口點、評估敵方巡邏路線並確認撤離路徑。 |
| **搜刮（回收 / Retrieve）** | 獲取高價值物資 | 中等至高 | 定位異常物件、管控彈藥存量並清除優先威脅。 |
| **撤離（返回 / Return）** | 安全逃回基地 | 高至極高 | 在持續壓迫下前往撤離信標處，確保戰利品安全帶回。 |

如果你未能成功撤離，將面臨失去該次行動中所獲取之全部珍貴物資的風險。在與大量怪物群交戰之前預先規劃好逃生路線，能確保你不會被困在死胡同中。

## 武器庫與戰鬥機制

遊戲中的戰鬥仰賴標準的第三人稱射擊彈道，並結合對戰況的靈活應變。不同的敵人具有各異的行為模式，因此武器的選擇至關重要。

### 可用武器類型

每種槍械都在特定的交戰距離內表現出色，並且需要嚴格控制開火節奏，以防在戰鬥中途耗盡彈藥。

| 武器類型 | 最佳射程 | 彈藥消耗 | 戰術定位 |
| :--- | :--- | :--- | :--- |
| **原型手槍 (Prototype Handgun)** | 近至中距離 | 低 | 可靠的備用武器；非常適合清理遊蕩的小型異常體並節省主武器彈藥。 |
| **雙管霰彈槍 (Double-Barreled Shotgun)** | 近距離 | 中等 | 對付極具攻擊性、快速逼近的近戰怪異生物具有強大的爆發傷害。 |
| **半自動狙擊步槍 (Semi-Automatic Sniper Rifle)** | 遠距離 | 低至中等 | 可在安全視線範圍內對單一目標進行高精準度狙殺。 |

在管理背包空間的同時監控即時彈藥存量至關重要。對著周遭的任何聲響盲目開火，會讓你在高階精英異常體現身時毫無還手之力。

## 異化技能與戰術能力

單靠槍械並不能完全保證你在面對超自然實體時生存下來。玲緒奈擁有獨特的超自然力量——**異化技能（Anomalization Skills）**，使玩家能在進攻和防守兩端掌控戰局。

將技能融入你的常規 **anomalith gameplay** 循環中，可以創造安全換彈、重新調整站位的機會，或是在不消耗稀缺彈藥庫存的情況下殲滅密集的敵人群。

### 技能功能與應用

| 技能類別 | 作戰效果 | 推薦戰鬥場景 |
| :--- | :--- | :--- |
| **進攻型異化** | 釋放集中的扭曲現實打擊 | 破壞裝甲敵人的弱點或對成群敵人進行控場。 |
| **防禦型異化** | 產生屏障力場或進行閃避位移 | 逃脫死角包圍、在突發伏擊中存活，或重新找回戰術節奏。 |
| **輔助調諧** | 增強感官反饋與探測能力 | 精準定位隱藏物件、撤離信標以及偽裝的異常體。 |

在頭目戰以及激烈的撤離防守階段，平衡技能冷卻時間與槍械射擊能確保火力壓制不間斷。

## 裝備成長、工作室升級與外觀自訂

你從異常區域帶回的一切資源，都會直接送入對策室的研究設施中。在研究主管伏見伊万里（Imari Fushimi）的帶領下，工作室可讓你將未加工的異常遺物轉化為強力的升級。

### 升級材料與組件

| 材料名稱 | 獲取來源 | 主要用途 |
| :--- | :--- | :--- |
| **連接磚 (Linked Tiles)** | 環境解謎與異常裂隙 | 防護服防禦的結構強化與屬性調校。 |
| **高級超現實槍械零件 (Advanced Surreal Firearm Parts)** | 精英異常體掉落與上鎖箱子 | 解鎖武器傷害階級、彈匣容量升級與後坐力控制。 |
| **警戒呼叫器 (Warning Pagers)** | 高危險區域搜刮回收 | 製作探測護身符與危險感應雷達升級。 |
| **射擊晶片 (Shooting Chips)** | 目標完成與支線任務 | 模組化屬性強化，例如 `[Power +]` 用以提升基礎 DPS。 |

### 外觀自由度

玩家的裝備成長並不會將外觀造型與裝備屬性綁定。外觀系統將外型與底層屬性完全解耦，讓你可以自由穿戴「武裝女高中生」制服或聯動造型等特色服裝，而完全不會犧牲防禦力或火力數值。

## 精通 ANOMALITH 玩法的必備技巧

若將這款遊戲當作街機風格的無腦射擊遊戲來玩，將會迅速招致失敗。將以下基本戰術規則融入你的 **anomalith gameplay** 實戰中，能大幅提升你的撤離成功率：

* **節省大口徑彈藥：** 將狙擊槍與霰彈槍彈藥留給高威脅目標。利用手槍或基礎進攻技能清理落單的偵察單位。
* **及早摸清閾限地圖結構：** 昭和風的建築結構經常會自我循環或扭曲變形。牢記適合在撤離時風箏怪物的寬敞走廊。
* **留意精神穩定度道具：** 在耗時較長的探索中攜帶消耗品「鎮靜劑」，以減輕在強烈異常環境中所受到的負面狀態。
* **優先查看工作室任務板：** 定期造訪工作室的任務板以接取可選委託（例如「矛盾異界應對」任務），藉此解鎖獨特的研發道具。
* **細聽聲音線索：** 在肉眼確認之前，聲音在偵測潛伏的異常體方面扮演關鍵角色。使用專門的音訊預設設定來追蹤逼近的威脅。

## 常見問題 (FAQ)

### ANOMALITH 屬於什麼遊戲類型？
ANOMALITH 是一款由 FuRyu 開發並發行的第三人稱生存射擊與動作角色扮演（ARPG）遊戲。它融合了 1980 年代昭和時期的復古美學、心理恐怖、閾限空間探索以及撤離式搜刮玩法。

### ANOMALITH 玩法中的撤離循環是如何運作的？
在每次行動中，你需要潛入異常區域、完成調查目標、收集鍛造材料並與超自然實體作戰。你必須安全抵達撤離點，將搜刮到的物資帶回工作室進行裝備鍛造與武器升級。

### 我可以在不損失屬性加成的情況下更換角色外觀嗎？
可以。遊戲內建幻化風格的外觀系統，角色外表與裝備屬性完全分開，讓你能自由自訂玲緒奈的外觀造型。

### ANOMALITH 是單人遊戲還是多人遊戲？
ANOMALITH 是一款以劇情為核心的單人遊戲體驗，聚焦於玲緒奈穿梭於異常維度的冒險旅程，並由資深劇本作家田中羅密歐（Romeo Tanaka）打造豐富的故事情節。
