## 故事梗概：在異象區中求生

故事設定在 20██ 年的近未來日本，隨著災難性的「異象區」（Anomaly Zones）無預警地在各個城市區域蔓延，現實世界開始分崩離析。政府為此成立了異象區對策室，負責偵察、封鎖並從這些扭曲現實的空間中回收物資。

玩家將化身為 17 歲的少女**水無月玲央奈**（Reona Minazuki）。在摯友消失於異象區後，她毅然自願成為一名異象潛入者（Anomaly Diver）。然而，在她災難性的首次潛入任務中，玲央奈的整支小隊被簡稱為「異象體」（Anomalies）的詭異克蘇魯式實體全滅。

作為唯一的倖存者，玲央奈體內潛藏的超自然突變覺醒，賦予了她超常能力。配備戰術槍械與不斷進化的能力，她必須深入深淵，揭開摯友失蹤背後的真相、自己產生突變的身體，以及異象產生的源頭。

## 核心玩法：「潛入、回收、撤離」

遊戲的核心循環建立在高度緊張的撤離模式上：**潛入、回收、撤離**。玩家必須在極大壓力下管理有限資源、克服不斷變化的環境，並做出關鍵的戰術決策。

```
[進入異象區] ➔ [戰鬥與搜刮] ➔ [尋找撤離點] ➔ [基地升級與配裝]
```

### 異象區探索機制

異象區內的環境完全顛覆了常規物理定律，將熟悉的城市空間變成了令人失去方向感的空間謎題：

* **重力反轉建築群：** 穿梭於地板、牆壁與天花板會動態調換位置的住宅公寓大樓中。
* **扭曲蠕動的走廊：** 在交火過程中會扭曲、延伸並改變射擊視野的狹窄室內走廊。
* **無限增殖的商店街：** 無限複製延伸的商業街區，需要玩家標記路徑以避免陷入無盡循環。

### 戰術槍戰與異象化技能

生存的關鍵在於精打細算的資源管理。玩家不能盲目掃射；每一發彈藥、每一組消耗性繃帶與輔助道具都必須妥善規劃。

| 戰鬥核心要素 | 特點 | 遊戲內實際應用 |
| :--- | :--- | :--- |
| **槍械選擇** | 武器相性搭配 | 根據怪物類型在主彈道步槍、散彈槍與精準武器之間切換。 |
| **背包欄位** | 空間與負重限制 | 在撤離前必須在攜帶多餘彈藥或高價值神器之間做出取捨。 |
| **異象化技能** | 12 種突變能力 | 觸發玲央奈的覺醒狀態，啟動攻擊爆發、防禦護盾或扭曲現實的閃避動作。 |
| **撤離路線** | 動態逃生信標 | 在生物穩定性惡化或彈藥耗盡前，抵達指定的撤離區域。 |

## 基地運作：自訂、升級與世界觀背景

從潛入任務中安全生還後，你可以在行動基地兌換收集到的物資。在此處，前期的充分準備將直接決定你下一次探險的生存機率。

### 裝備與自訂系統

* **槍械配件：** 改裝後座力模式、槍口初速、彈匣容量以及元素傷害屬性。
* **神器銘刻：** 鑲嵌從異象深處回收的神秘遺物，用以調整閃避速度、耐力恢復以及突變技能冷卻等被動屬性。
* **9 格裝備系統：** 玲央奈的外觀裝備分為 9 個模組化欄位，各欄位均會影響核心防禦力與實用性數值。
* **外觀幻化系統：** 角色外觀可完全與裝備數值脫鉤，讓玩家在不犧牲防禦效益的前提下，自由打造玲央奈的個人造型。

| 基地設施 | 功能 | 玩家增益 |
| :--- | :--- | :--- |
| **槍械工坊** | 改裝武器零件與配件 | 依個人偏好自訂武器後座力、裝填速度與操作手感。 |
| **神器實驗室** | 裝備異象區遺物 | 提供強大的屬性加成與技能形態改造。 |
| **潛入報告檔案庫** | 分析已擊敗的異象體 | 揭示怪物的弱點部位、生成習性與掉落機率。 |
| **潛入者宿舍** | 承接支線任務 | 加深與後勤支援人員的關係，並揭開隱藏的背景故事。 |

## 新手入門策略指南：如何做好潛入準備

在異象區的高壓環境中生存，需要養成嚴謹的作戰習慣。以下是每位潛入者在進入 **ANOMALITH Switch 2** 的戰場時應遵循的基本準則：

1. **規劃路線優先於戰鬥：** 單純擊殺普通怪物並不會帶來額外獎勵。如果一場遭遇戰會消耗過多彈藥，請利用兩側的側翼走廊繞過敵人。
2. **合理分配背包空間：** 出發時務必保留至少四個空白背包欄位。將背包塞滿基礎物資會導致你無法拾取撤離點附近的高階稀有神器。
3. **熟練掌握技能循環：** 玲央奈的 12 種異象化技能並非單純的保命技能，而是強力的進攻增幅手段。將控場技能與近距離散彈槍射擊相結合，即可快速清場。
4. **研讀潛入報告：** 每一隻被擊敗的怪物都會在基地檔案庫中記錄關鍵生態數據。仔細研究其元素弱點能大幅縮短擊殺時間。

當你踏入 **ANOMALITH Switch 2** 的世界時，提早掌握這些基本技巧將能有效避免在深層異象探索中蒙受慘重的裝備損失。
