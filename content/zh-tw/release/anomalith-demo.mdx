## ANOMALITH 試玩版內容亮點

本次可遊玩的體驗版將引導玩家認識主角水無月玲央奈（Reona Minazuki）——一名 17 歲的女學生，她加入了由政府支持的「異象區域對策室」，成為一名涉足險境的「潛水員（Diver）」。在摯友加藤亞理紗（Arisa Kato）於一處異化的購物中心失蹤後，玲央奈毅然潛入扭曲現實的異常空間，直面被稱為「異象（Anomalies）」的致命超自然實體。

在試玩版中，玩家將能親自體驗遊戲的核心循環：**潛入、回收、歸還（Dive, Retrieve, and Return）**。能否生還完全取決於你搜刮材料、節省寶貴彈藥的能力，並在被敵對實體包圍前及時啟動撤離程序。

| 特色重點 | 遊戲內功能 | 戰略重要性 |
| :--- | :--- | :--- |
| **潛入系統 (Dive System)** | 部署至超現實且不斷變化的異象區域 | 決定探索目標與危險等級 |
| **回收機制 (Retrieval Mechanics)** | 收集異象物品與製作戰利品 | 為武器研發與裝備升級提供資源 |
| **撤離點 (Extraction Points)** | 返回安全基地的逃生路線 | 若陣亡將面臨失去所有收集物資的高風險 |
| **異象化技能 (Anomalization Skills)** | 主動施放的超自然戰鬥能力 | 在爆發性進攻與戰術防禦之間取得平衡 |

參與 **anomalith demo** 測試的玩家會立即感受到其沉穩且講究的節奏。不同於無腦的突突突射擊，遊戲中的每一發子彈都至關重要，需要玩家謹慎評估威脅並進行戰術走位。

## 核心遊戲系統與養成循環

本作的核心結合了心理生存恐怖與反應靈敏的第三人稱射擊機制。要想在探索中生還，必須平衡槍械武器配置與在區域內覺醒的主動超自然技能。

```
[ 進入異象區域 ] ➔ [ 搜刮材料與物品 ] ➔ [ 擊敗異象實體 ] ➔ [ 安全撤離 ] ➔ [ 打造裝備與升級技能 ]
```

### 1. 戰鬥與異象化技能

玲央奈擁有從副武器到重型槍械的多樣軍火庫，並輔以超自然技能。來自展會實機試玩的社群反饋強調了「針對敵人弱點搭配武器類型」的重要性。若異象實體逼近身邊，防禦技能的施放時機將直接決定撤離成功與任務失敗。

### 2. 製作與自訂系統

從深處回收的異象物品可供異象區域對策室研發先進武器、特殊彈藥以及模組化戰鬥裝備。

值得注重外觀的玩家高興的是，外觀裝扮與戰鬥數值是完全分離的。你可以自由自訂玲央奈的視覺風格——包含多種水手服變體與戰術服裝——而無需犧牲防禦護甲值或傷害加成。

## 首次潛水生存技巧指南

初次踏入異象區域可能會令人方向迷失。在遊玩 **anomalith demo** 時，請牢記以下實用建議：

1. **聽覺線索至上：** 異象實體在閾限走廊中現身前，通常會發出獨特的音效扭曲。建議配戴耳機並開啟定向音效。
2. **對普通怪物節省彈藥：** 切勿對普通的徘徊實體浪費高級散彈槍子彈或步槍彈藥；多利用副武器精準射擊弱點。
3. **密切監控理智／鎮靜劑存量：** 長時間處於超現實幾何空間中會消耗精神專注度。請將鎮靜劑設為快捷鍵，以應對突如其來的難度飆升。
4. **及早將升級材料入庫：** 在 **anomalith demo** 中探索時，一旦取得關鍵製作零件，應立即返回撤離點，切勿為了微薄的物資冒著全滅失利的風險。
