## 故事背景、角色陣容與全明星製作團隊

《ANOMALITH》的世界觀將玩家帶入 20██ 年的架空現代日本。城市景觀中毫無預警地頻繁出現被稱為「異變區（Anomaly Zones）」的詭異現象。17 歲的主角水無月玲央奈（Reona Minazuki）正與摯友加藤有紗（Arisa Kato）在商業購物中心逛街時，突如其來的「異變」將整個設施撕裂吞噬，導致有紗下落不明。

玲央奈毅然加入政府資助的異變區對策室，成為一名專門的「潛水員（Diver）」，誓要找回失蹤的摯友。在她遭遇毀滅性打擊的首次潛入行動中，體內潛藏的未知超自然力量覺醒，使她成為唯一能夠在這片扭曲現實的極端環境中自由穿梭並生還的倖存者。

## 核心遊戲循環：潛入、回收與撤離

從核心機制來看，《ANOMALITH》巧妙結合了戰術第三人稱射擊（TPS）槍戰、撤離型生存機制與動作 RPG 的成長養成要素。若想在這片危險區域生存，玩家必須在主動進攻與保守物資搜刮之間取得精密平衡。在 **《ANOMALITH》發售日** 來臨前掌握這些系統運作方式，將為您帶來顯著的戰略優勢。

```
┌────────────────────────────────────────────────────────┐
│               《ANOMALITH》核心遊戲循環                 │
├────────────────────────────────────────────────────────┤
│  1. 整備出發   → 配置武器、彈藥補給與外觀服裝         │
│  2. 潛入異域   → 進入扭曲現實的危險「異變區」         │
│  3. 奮勇求生   → 運用 TPS 槍法與異變技能迎戰敵性異變體 │
│  4. 搜刮回收   → 拾取異變遺物與稀有升級素材           │
│  5. 安全撤離   → 成功撤出並在工作台製作強力強化裝備   │
└────────────────────────────────────────────────────────┘
```

### 戰術戰鬥與異變能力

一般的槍械武器僅僅是戰鬥的一半。在探索以 1980 年代復古美學與空間閾限感為靈感的動態變異場景時，您將面對名為「異變體（Anomalies）」的敵對實體。

- **戰術武器切換：** 不同的異變體具有特定的弱點屬性；根據戰況在近距離霰彈槍、高射速隨身副武器與精確射擊步槍之間靈活切換至關重要。
- **異變技能（Anomalization Skills）：** 玲央奈可以使用兼具進攻與防禦效果的超自然能力，藉此扭轉戰局、擊暈高威脅目標，或抵擋致命的空間撕裂異常。
- **外觀自訂幻化（Transmog）：** 裝備升級會改變武器與防具的數值，但角色的外觀可以獨立設定調整，讓玩家在不犧牲數值加成的前提下自由搭配服裝外觀。

## PC 系統需求與無障礙輔助功能

在迎來 **《ANOMALITH》發售日** 並投身遊戲之前，請先確認您的桌上型電腦或筆記型電腦配備符合官方硬體要求。本作基於 DirectX 11 運行，需要 Windows 11 64 位元作業系統以及 40 GB 的可用硬碟空間。

### 官方系統配備需求

| 硬體組件 | 最低系統需求 | 建議系統規格 |
| :--- | :--- | :--- |
| **作業系統** | Windows 11 (64 位元) | Windows 11 (64 位元) |
| **處理器 (CPU)** | Intel Core i5-6600 / AMD Ryzen 5 2600 | Intel Core i5-10400 / AMD Ryzen 5 3600 |
| **記憶體 (RAM)** | 12 GB RAM | 16 GB RAM |
| **顯示卡 (GPU)** | NVIDIA GTX 1050 Ti / AMD Radeon RX 5500 XT | NVIDIA RTX 2060 / AMD Radeon RX 5700 XT |
| **DirectX 版本** | Version 11 | Version 11 |
| **儲存空間** | 40 GB 可用空間 | 40 GB 可用空間（建議使用 SSD） |

### 無障礙與視聽輔助設定

FuRyu 整合了六項重要的輔助功能開關，以確保所有玩家都能獲得流暢的入門體驗：

- **難度自訂調節：** 可自由調整敵人的傷害數值與地圖物資豐富度，以符合您期望的挑戰難度。
- **視覺輔助選項：** 提供完整字幕支援、字體大小縮放調節以及清晰的高對比文字顏色顯示。
- **音訊獨立控制：** 具備角色語音、環境音效及背景音樂的獨立音量滑桿。
- **多語言支援：** 完整日語語音，並配備多語言介面與字幕（英語、日語、簡體中文、繁體中文及韓語）。
