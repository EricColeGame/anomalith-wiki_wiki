## Anomalith 試玩預告片揭示的故事世界觀與背景設定

《ANOMALITH》背景設定於 20██ 年的架空未來日本，玩家將置身於一個破碎的現實世界中——詭異而危險的異象突然撕裂了正常的城市景觀。故事圍繞著 17 歲的水無月玲央奈（Reona Minazuki）展開，她原本是一名普通學生，卻在一場災難性的購物中心事件中徹底改變了命運。當她最親密的好友消失在突如其來的次元裂隙空間中時，玲央奈毅然加入了政府成立的「異常區域對策室」，成為一名官方認證的「潛入者」（Diver）。

```
購物中心事件（20██年） ➔ 異常區域顯現 ➔ 玲央奈入伍成為潛入者 ➔ 能力覺醒 ➔ 深淵探索
```

在 **anomalith demo trailer** 中奠定的基調營造出一個陰鬱沉重、氛圍感極強的世界，潛入者在執行任務時隨時面臨喪命的危險。在玲央奈的首次潛入任務中，她在整支小隊全軍覆沒的慘烈遭遇戰中倖存下來，並覺醒了一種神秘力量，讓她能夠駕馭源自異常現象的戰鬥能力。在堅定信念的驅使下，她深入異常區域的核心，誓要救回好友並揭開政府對該現象隱瞞的真相。

## 核心玩法循環：潛入、回收與撤離

本質上，《ANOMALITH》將高張力的第三人稱射擊與輕度撤離生存機制（Extraction-lite）完美結合。當玩家準備執行任務時，將進入難以預測的異次元區域，在此之中，走位判斷、彈藥控制與威脅評估將決定生死。

```
準備階段（工坊配置） ➔ 滲透介入（區域潛入） ➔ 異象交戰與物資搜刮 ➔ 安全區撤離
```

遊戲的核心圍繞三步循環展開：
1. **潛入（Dive）**：部署至重力異常、建築奇異扭曲且遊蕩著名為「異象」（Anomalies）怪物的極不穩定區域。
2. **回收（Retrieve）**：搜刮關鍵的異常物品、武器設計圖與製作素材，同時極力壓低彈藥消耗。
3. **撤離（Return）**：在環境不穩定性徹底吞噬角色之前，迅速趕往指定的撤離點。

* **解鎖方式**：完成初始教學潛入任務後，可在中央工坊據點內的任務公告板領取。

## 給新晉潛入者的戰術指南

結合 **anomalith demo trailer** 展示的戰術機制與社群玩家實測心得，每次出發前做好周密準備至關重要：

* **節省大口徑彈藥**：將狙擊步槍子彈留給高威脅的菁英異象。面對雜兵與環境低級怪時，盡量使用基礎副武器與近戰技巧。
* **以撤離標記為第一優先**：稀有素材掉落時很容易讓人貪心，但若錯過撤離倒數計時，空間坍塌會直接導致全隊覆滅。
* **儘早升級射擊晶片**：裝備威力強化型晶片可顯著縮短擊殺帶護盾異象敵人的時間（TTK）。
* **時刻留意環境音效**：不穩定區域具有異變的音效環境；高頻音效失真通常預示著即將到來的敵人伏擊或空間裂隙。

如同宣傳物料與緊湊刺激的 **anomalith demo trailer** 所展示，熟練掌握空間意識與高效的裝備調配，將是揭開 20██ 年事件背後真相的基石。
