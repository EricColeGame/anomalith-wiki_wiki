## 什麼是 Anomalith 閾限空間？

故事的核心圍繞著不良高中少女水無月玲奈展開。在一次普通的購物中心之行演變成超自然災難後，她被捲入了政府的秘密行動中。在朋友消失於異常現象後，玲奈被迫擔任官方「潛入者（Diver）」——專門負責深入被封鎖的異次元區域（稱為「區域（Zone）」）的特工。

環境設計極大程度地借鑑了經典的過渡性建築風格：無止盡的企業長廊、廢棄的檢傷分類診所，以及被抽離人類痕跡的空曠公共空間。這些地點令人感到異常熟悉卻又徹底詭異，呼應了安德烈·塔可夫斯基的《潛行者》等電影靈感以及網路時代的都市傳說。

| 核心區域特質 | 描述 | 對遊戲玩法的影響 |
| :--- | :--- | :--- |
| **建築熟悉感** | 地點類似日常設施（醫院、辦公室、商場）。 | 營造出具欺騙性的視線與迷宮般的格局配置。 |
| **空間孤立感** | 完全缺乏平民活動，並伴隨低沉的環境音效。 | 聲音線索成為偵測逼近威脅的關鍵指標。 |
| **異常不穩定性** | 越深入區域內部，現實維度瓦解得越嚴重。 | 干擾路徑辨識，並觸發高等級變異怪物的遭遇戰。 |
| **依賴撤離點** | 各區域皆被軍事路障徹底封閉。 | 玩家必須建立便攜式裂隙點以安全帶回收集的遺物。 |

## 核心潛入機制：探索與撤離

在遊戲的異常區域中穿梭，需要在探索速度與生存風險之間取得平衡。作為一名潛入者，你的首要目標是調查異常現象、回收珍貴遺物、為古怪的研究人員收集生物樣本，並尋找失蹤同伴的相關線索。

```
進入收容區域 ➔ 搜刮遺物與彈藥 ➔ 部署裂隙傳送門 ➔ 消滅變異威脅 ➔ 帶回戰利品撤離至基地
```

### 區域機制深度解析

1. **環境導航：** 地圖包含非線性走廊，門扉可能會出人意料地形成迴圈，或突然通往死胡同。
2. **安全避難錨點：** 在每次探索過程中，玩家都可以設置臨時傳送門站點。這些可部署的裂隙能讓你在迎戰高風險目標前，立即將搜刮到的裝備傳送回基地。
3. **異常物質收集：** 被擊敗的變異怪物會掉落特殊材料。將這些材料交易給基地的研究人員，即可解鎖高級槍械升級與角色特徵被動。

| 機制類型 | 系統細節 | 戰術建議 |
| :--- | :--- | :--- |
| **網格化背包** | 受《惡靈古堡》啟發的物品欄網格，具備自動整理功能。 | 將武器置中擺放，並沿著邊緣堆疊回復道具。 |
| **單向傳送門** | 可放置於指定區域節點的可部署轉移點。 | 在進入頭目房間之前，立即將高級製作素材送回基地。 |
| **彈藥儲藏點** | 分散於辦公桌和醫療推車中的豐富資源點。 | 可對群聚敵人全力掃射，無需擔心儲備見底而卡關。 |
| **樣本交易** | 與回收之生物奇異物掛鉤的貨幣系統。 | 前期優先提升被動防禦特徵，以應對大批近戰怪物的圍攻。 |

## 戰鬥系統：槍械 vs. 變異能力

與純粹的心理恐怖步行模擬遊戲不同，**Anomalith 閾限空間** 中的戰鬥將靈敏的第三人稱射擊與駭人的生物超能力融為一體。在首次探險初期，玲奈便遭到了區域核心異常的感染，這賦予了她將肉體轉變為毀滅性扭曲變異形態的能力。

### 射擊戰術

早期玩家的體驗顯示遊戲中的彈藥供應相當充足，這意味著戰鬥遭遇更偏向快節奏的群體壓制，而非極端的資源節約。你將會使用標準手槍、戰術霰彈槍以及高射速衝鋒槍，用以阻截蜂擁而至的怪異生物。

### 異形變身

當常規槍械無法清除狹窄走廊中的敵人時，啟動玲奈的變異形態將徹底改變戰鬥走向。此狀態可解鎖高威力的近戰攻擊、動能控場技能以及強化的位移身法，能夠輕易撕碎裝甲畸變體。

| 戰鬥風格 | 主要優勢 | 最佳應對遭遇 | 資源消耗 |
| :--- | :--- | :--- | :--- |
| **彈道火力** | 高精準度、安全交戰距離、多種彈藥類型。 | 走廊隘口以及飛行或遠程異常實體。 | 標準彈藥箱 |
| **變異形態** | 巨額範圍傷害、霸體狀態、快速突進技能。 | 密閉房間伏擊與精英小頭目戰。 | 變異計量表充能 |
| **拉扯與打擊混合流** | 用霰彈槍打出硬直，再以變異重擊收尾。 | 包含迅捷潛行者與重型蠻力怪的混合敵潮。 | 平衡消耗耐力與彈藥 |

## 區域環境：醫院與辦公大樓對比

極具氛圍感的沉浸體驗是本作的最大亮點。玲奈充滿活力、極具叛逆風格的街頭服飾，與隔離區陰暗單調的衰敗景象形成了強烈視覺對比，讓每次潛入的緊張感倍增。探索不同的 **Anomalith 閾限空間** 會面臨各具特色的空間挑戰，需要採取不同的戰術應對。

| 區域板塊 | 主導視覺基調 | 主要威脅類型 | 推薦配裝 |
| :--- | :--- | :--- | :--- |
| **廢棄醫療中心** | 冰冷死白的色調、鏽蝕的輪椅病床、閃爍的日光燈管。 | 快速爬行的畸形怪物與從天花板突襲的潛伏者。 | 壓動式霰彈槍、閃光彈、醫療注射器。 |
| **企業辦公大樓** | 單調沉悶的隔間迷宮、浸水發霉的地毯、黑屏的電腦螢幕。 | 隱藏在隔板牆後的伏擊群怪。 | 大容量衝鋒槍、破片手榴彈。 |
| **地下商場核心** | 破碎的店面櫥窗、停擺的手扶梯、嗡嗡作響的霓虹招牌。 | 重裝變異巨怪與異常能量裂縫。 | 突擊步槍、變異爆發技能。 |

### 狹窄空間應對指南

來自試玩版玩家的反饋指出，房間清剿戰往往在門扉於身後反鎖時突然觸發。在這些狹窄的空間內，維持空間感知能力至關重要：

- **緊貼外圍邊緣：** 切勿在隔間群的正中央作戰，否則敵人可能會從 360 度全方位湧出。
- **留意嗡鳴頻率：** 在異常現象於附近顯現之前，日光燈的嗡鳴聲往往會改變音調。
- **預先放置傳送門：** 在觸發大型辦公樓層的封鎖事件前，先在門廳外預先放下撤離傳送門。

## 區域潛入生存策略

要克服 **Anomalith 閾限空間** 內的超自然危險，需要敏捷的反應與明智的物品欄規劃。善用以下行動守則來優化你的每一次探險：

### 1. 熟練掌握自動整理物品欄
雖然遊戲採用了正統的網格式背包配置，但內建的自動整理功能可避免在緊張戰鬥中浪費時間。請將重型武器指派至快捷欄位，以便在敵人逼近時能無縫切換。

### 2. 善用傳送門保存點
切勿將沉重的素材一直囤積在主要背包中。每當發現異常節點時，立即建造傳送門錨點，將多餘的生物材料直接送回安全處。這樣即使遭遇突發伏擊而陣亡，也能確保探索進度不白費。

### 3. 保持侵略性的進攻節奏
與傳統生存恐怖遊戲相比，本作的彈藥掉落相對豐富，因此被動龜縮防守很少能帶來收益。善用霰彈槍造成的硬直創造破綻，隨後啟動玲奈的變異肢體，在聚集的敵群形成包圍網前迅速將其剿滅。

## 常見問題

### Anomalith 的閾限空間與其他生存恐怖遊戲有何不同？
與節奏緩慢的純恐怖遊戲不同，**Anomalith 閾限空間** 將超現實、令人不安的建築風格與爽快的第三人稱射擊及異形變身機制相結合。你不再只是單純躲避威脅，而是主動獵殺異常實體、部署撤離傳送門並採集生物材料來推動角色成長。

### 玲奈的變異能力可以升級嗎？
可以。透過收集區域內被擊敗實體掉落的稀有物質，玩家可以與基地的研究人員進行交易，以解鎖全新的戰鬥技能、增強被動防禦屬性，並提升玲奈變身狀態下的毀滅威力。

### 遊戲中的資源管理難度高嗎？
根據早期試玩版本的玩家體驗反饋，本作的資源管理偏向親民易上手，而非極端硬核懲罰。憑藉慷慨的彈藥掉落、自動整理的物品欄網格以及可隨時部署的回收傳送門，遊戲更加注重戰術走位與氛圍張力，而非極端的物資匱乏。
